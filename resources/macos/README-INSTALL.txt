OBS Apple Borders — macOS install
=================================

1. Double-click the .pkg installer in this disk image.
2. Follow the prompts (Install for me only).
3. Fully quit OBS Studio (OBS → Quit), then open it again.
4. Add a filter or source: right-click a source → Filters, or use + → Sources.

The plugin installs to:
  ~/Library/Application Support/obs-studio/plugins/obs-apple-borders.plugin

If macOS says the package is from an unidentified developer (unsigned builds):
  Right-click the .pkg → Open → Open.

Need help? https://github.com/dyckdavid/obs-apple-borders
